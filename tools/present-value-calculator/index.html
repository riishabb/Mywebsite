Present Value Calculator

Find today’s value of one future amount.

How to use this calculator

Present value discounts the future amount over the entered number of years. Use a rate consistent with the risk, currency and timing of the cash flow.

Important limitations

The result is sensitive to the discount rate and does not establish which rate is appropriate for accounting, valuation or investment decisions.

Free browser-based calculation for preliminary analysis. Review contractual terms and obtain appropriate professional advice before making a financial decision.
