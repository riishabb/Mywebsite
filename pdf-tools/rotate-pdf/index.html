Rotate PDF Pages

Rotate selected PDF pages by 90, 180 or 270 degrees directly in your browser.

How to use this rotate pdf pages tool

Add a PDF, select page numbers and a rotation angle, then process and download the result.

Private processingFiles remain on this device.

What to know before you begin

Rotation changes page orientation metadata; it does not perform optical character recognition or edit the page contents.

File privacy

The processing is performed by JavaScript running in your browser. The tool does not send the contents of your selected files to this website or retain them after you refresh or close the page.
