Combine Selected Pages from PDFs

Pick pages from several PDF files and combine only those pages into one new document.

PDF tools

How to use this combine selected pages from pdfs tool

Add multiple PDFs and enter selections using file-number:pages, for example 1:1-2, 2:4.

Private processingFiles remain on this device.
No accountUse the tool without registration.
Free to useNo payment or watermark is added.

What to know before you begin

File numbers follow the order shown in the queue. Reorder the files before entering your page selections.

File privacy

The processing is performed by JavaScript running in your browser. The tool does not send the contents of your selected files to this website or retain them after you refresh or close the page.
